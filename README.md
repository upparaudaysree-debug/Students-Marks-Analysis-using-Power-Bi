# Student Marks Analysis Dashboard 📊

## 📌 Project Overview

The **Student Marks Analysis Dashboard** is a Power BI project created to analyze the academic performance of **200 students**. The dashboard provides a clear and interactive view of student marks, grades, pass/fail results, and performance across different subjects, departments, and genders.

## 🎯 Objectives

* Analyze overall student performance.
* Identify passed and failed students.
* Compare performance across different subjects.
* Analyze department-wise and gender-wise performance.
* Understand grade distribution.
* Identify students who may need improvement.

## 🛠️ Tools Used

* **Power BI** – Dashboard and data visualization
* **Excel** – Dataset
* **DAX** – Calculations and measures

## 📊 Dashboard Features

* Total Students
* Pass Students
* Fail Students
* Average Marks
* Highest Total Marks
* Pass vs Fail Analysis
* Grade Distribution
* Subject-wise Average Marks
* Average Marks by Department
* Gender-wise Average Marks
* Department Filter
* Gender Filter
* Result Filter
* Student Details Table

## 📁 Dataset

The dataset contains **200 student records** with the following fields:

* Student ID
* Name
* Gender
* Department
* Math
* Science
* English
* Computer
* Total
* Average
* Grade
* Result

## 🔍 Key Insights

The dashboard helps users quickly understand:

* Overall academic performance.
* Number of students who passed and failed.
* Which subjects have higher or lower average marks.
* Which departments perform better.
* Grade distribution among students.
* Individual student performance.
